* Overview

This repository contains a coherent set of tools designed to improve and
structure LaTeX export from Org mode, with a particular focus on:

- custom LaTeX classes,
- dedicated Beamer themes,
- Org configuration files for LaTeX,
- an Emacs Lisp integration to declare and use these classes.

The repository follows an organization compatible with a local =~/texmf=
installation and with an Org mode oriented Emacs configuration.

* Repository structure

** =docs/=

Contains documentation related to the Boost LaTeX classes:

- =Using-the-Boost-LaTeX-Class.pdf=
- =Using-the-Boost-LaTeX-Class.tex=

These files describe how to use the LaTeX classes provided.

** =lisp/=

- =org-boost-latex-classes.el=

Emacs Lisp file intended to declare *custom LaTeX classes for Org mode*. It
enables Org to export documents using the classes defined in this repository.

** =org/=

=.setup= files intended to be included in Org files; for example:

- =beamer-only.setup=
- =latex-fonts.setup=
- =latex-hyperref.setup=
- =latex-layout.setup=
- =latex-listings.setup=

These files are used to centralize reusable LaTeX settings during export from
Org mode.

** =texmf/=

Directory structure compliant with a local TeX installation.

*** =texmf/tex/latex/boost/=

Custom LaTeX classes and styles:

- =.cls= classes (article, report, book),
- shared =.sty= style files.

These files define a coherent family of LaTeX documents under the "boost" prefix.

*** =texmf/tex/latex/beamer-boost/=

Custom Beamer themes:

- theme files =.sty=,
- corresponding Org sources =.org=.

Those themes are generated from and documented using Org mode.

*** =texmf/tex/latex/generic/images/=

Generic images used by the LaTeX classes or themes.

* Project goals

The project goals are:

- provide ready to use LaTeX classes,
- facilitate Org mode export to these classes,
- centralize recurring LaTeX settings,
- offer Beamer themes consistent with the document classes.

* Run the checks

Run the local regression tests with:

#+begin_src shell
make check
#+end_src

The regression test compiles a minimal =boostreport= document and checks that
numbered and unnumbered level-four entries are included and indented
consistently. It also checks that section headings stay within the page margins
with stepped horizontal offsets for chapter, section, subsection, and
subsubsection headings in landscape mode, and that portrait spacing is restored
afterward.

Nested itemize lists use compact blue square, filled-circle, and open-circle
markers at their first three levels. Circles are drawn with outer diameters
relative to the text's x-height: 0.7 ex for the filled circle and 0.6 ex for the
open circle, so the filled circle remains larger regardless of the text font.

Dependency checks also compile all three Boost classes with the default language
and the explicit =english= and =french= options, exercising equations and
references, colored long tables, listings, links, acronyms, boxes, and TODO
notes. They verify that =babel= precedes =listings=, that =babel=, =amsmath=, and
=longtable= precede =hyperref=, and that =todonotes= follows =hyperref=. The reusable
=boostlistings= and =boostboxes= styles are also tested with the standard =article=
class.

The classes apply their language selection after Babel's begin-document
initialization, so explicit language options are not overwritten. The checks
also verify the rendered TOC title: "Contents" or "Table des matières".

Org export tests cover class registration and explicit class options. They
compile French and English Org documents with all three classes, checking the
TOC title in the resulting PDFs. Tests run with =emacs -Q= and do not load a
personal Emacs configuration.

The checks require =lualatex=, =pdftotext=, and =emacs= with Org mode.

* Usage in Org mode

** LaTeX installation

Make sure TeX can find the classes:

1. Copy or link the =texmf/= directory into your local =~/texmf=.
2. Update the TeX file database if necessary:

#+begin_src shell
texhash ~/texmf
#+end_src

** Emacs installation

Make Org export use the =boostreport= class by adding the Lisp file to your Emacs
configuration:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/org-latex-themes/lisp")
(require 'org-boost-latex-classes)
#+end_src

The exact path depends on the local location of the repository.

Then select the class in your Org file:

#+begin_src org
#+LATEX_CLASS: boostreport
#+end_src

** Set document metadata in Org

Org standard metadata keywords are used to populate the LaTeX document.

For French or English documents, set both the Org language and the matching
LaTeX class option:

#+begin_src org
,#+LANGUAGE: fr
,#+LATEX_CLASS: boostreport
,#+LATEX_CLASS_OPTIONS: [final,french]
#+end_src

For English, use =#+LANGUAGE: en= and =[final,english]=. The LaTeX option controls
automatic titles such as "Table des matières" or "Contents". Synchronizing this
option automatically from =#+LANGUAGE:= is the responsibility of the user's
Emacs configuration (for example, Emacs Leuven), not this repository.

In your Org file:

#+begin_src org
,#+TITLE:     Your document
,#+AUTHOR:    Your name
,#+EMAIL:     Your email
,#+DATE:      \today
,#+DESCRIPTION: Short description of the document purpose.
,#+KEYWORDS:  Org mode, LaTeX, Emacs
,#+LATEX_CLASS: boostreport
#+end_src

What Org guarantees during LaTeX export:

- =#+TITLE:= → =\title{Your document}=
- =#+AUTHOR:= → =\author{Your name}=
- =#+DATE:= → =\date{\today}=

Regarding the additional fields:

- =#+DESCRIPTION:= is exported to LaTeX as document metadata (for example PDF
  metadata) when supported by the class and packages in use.
- =#+KEYWORDS:= is exported as LaTeX metadata in the same way.

The exact visual or semantic use of *DESCRIPTION* and *KEYWORDS* depends entirely
on:
- the LaTeX class (for example =boostreport=),
- and the packages it loads (for example =hyperref=).

** Include the repository's reusable LaTeX setup snippets (optional)

You may include the =.setup= files (provided in the =org/= directory) in an Org file
with:

#+begin_src org
,#+SETUPFILE: /path/to/org-latex-themes/org/setup/latex-hyperref.setup
,#+SETUPFILE: /path/to/org-latex-themes/org/setup/latex-listings.setup
#+end_src

The exact behavior depends on the content of each =.setup= file.

** Minimal complete Org example

#+begin_src org
,#+TITLE:     Your document
,#+SUBTITLE:  Project overview
,#+AUTHOR:    Your name
,#+EMAIL:     Your email
,#+DATE:      \today
,#+DESCRIPTION: Example document generated from Org mode.
,#+KEYWORDS:  Org, LaTeX, Emacs, Boost
,#+LATEX_CLASS: boostreport

,* Introduction

Some content.

,* Conclusion

More content.
#+end_src

Export with:

- =C-c C-e l l= to generate the LaTeX file, or
- =C-c C-e l o= to generate and open the PDF (depending on your configuration).

The resulting LaTeX file will include:

- =\documentclass{boostreport}= and
- standard title metadata.
